# Board software (SK-AM62B)

Everything in this folder runs on the SK-AM62B. Setup, wiring and checks: [docs/BOARD_SETUP.md](../docs/BOARD_SETUP.md).

| File | What it does |
|---|---|
| `blinktalk_board.py` | The board program: reads the AFE4950EVM, runs the eye-command model and heart rate, prints `BLINKTALK ...` lines. The laptop hub starts it automatically. |
| `afe4950.py` | AFE4950EVM driver over USB (TI GUI protocol) and recorder (`--seconds`, `--cue`, `--led-sweep`) |
| `heart_rate.py` | Heart rate and signal quality from the PPG channel, high/low alert |
| `eog/` | The eye-command recognizer in plain C: `eog.c` (filter, detector, 72 features, forest, blink counter), `eog_model.h` (the trained forest, generated by `training/`), `eog_api.c` + `recognizer.py` (Python binding), `eog_replay.c` (replay a CSV from the command line), prebuilt `libeog_aarch64.so` / `libeog_x86_64.so` |
| `afe_config/` | TI's AFE4950 register configuration (eye channel 500 Hz, PPG 50 Hz) |
| `tools/mock_evm.py` | Simulated EVM for testing without hardware |
| `test_board.py` | Replays recordings through the board program and checks the commands |
| `offline_packages/` | Installs SciPy on the board without internet |

Command line, from this folder on the board:
```
python3 blinktalk_board.py --led 12                     # live
python3 blinktalk_board.py --replay recordings/neal_left_every_3s.csv
python3 afe4950.py --seconds 20 --out recordings/check  # record
python3 heart_rate.py --ppg recordings/check_PPG.csv
```
